## Hi, I'm Thanh (Haku)

I'm a **Full-Stack Developer** based in Calgary, AB, Canada, specializing in Angular, Node.js, and Cloud Architecture. I build scalable web applications and enjoy sharing what I learn along the way.

## What I Do

I work across the full stack — from crafting responsive frontend interfaces in Angular and React, to designing backend APIs with Node.js/Express/NestJS, to deploying and orchestrating services on AWS using Docker, ECS, Lambda, and S3.

Lately I've been focused on:

- **Angular & TypeScript** — component architecture, state management, performance optimization
- **DevOps & CI/CD** — GitHub Actions pipelines, Docker multi-stage builds, AWS deployment automation
- **SEO for SPAs** — self-hosted prerender services with Puppeteer + Nginx bot routing
- **Cloud-native APIs** — serverless functions, PostgreSQL, REST/GraphQL

## Why This Blog

This site is where I document real-world issues I encounter and how I solve them — the kind of thing that doesn't make it into official docs but saves hours of debugging. Think of it as a public engineering notebook.

I write about:
- Bug investigations and fixes
- Architecture decisions and trade-offs
- Tools and workflows that improved my productivity
- Lessons from building production systems
